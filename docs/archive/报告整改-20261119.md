## 二、线上实测（2026-11-19 晚）

- 伪造 `cf-access-authenticated-user-email` 访问 `/console`、`/console/whoami`：均被 Access 边缘 302，未拿到控制台。
- 产物上传：`PUT` 内容与 sha 不符 → `422 hash_mismatch`；正确内容 → `200 stored`，返回 bytes。
- `/dl/synapse-agent-x86_64-linux-musl`：`HEAD 200`，`x-sha256: 92d415d3…`；`.sha256` 边车可取。
- 提交：`base_sha=zzz` → `422 base_sha_not_hex`；标题带 `AKIA…` → `422 secret_detected`。
- 水平越权：新签 `e2e-probe`（只有 poll/ack/report）带 `agent=doubao-client` 拉 inbox，只看到广播，看不到定向消息；替他人 ack → `403 not_your_message`；删除 agent → `403 admin_required`。
- 任务：`POST /x/admin/p/yanshi/tasks` → `200 {task_id:T-sec-1,state:open,seq:3}`；列表可读。
- 会话吊销：`POST /x/admin/security/revoke-sessions` → `{ok:true,epoch:"1"}`。
- Rust：本机 `synapse-agent init --endpoint http://example.com …` → 拒绝并退出。
- 控制台转义：node 实测 `<img onerror>` → `&lt;img …&gt;`，引号 → `&quot;`；`localStorage.setItem(KEY…)` 已无。
